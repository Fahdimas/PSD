Tugas Mingdep — Ekstraksi Fitur Citra & Klasifikasi (Rapi vs Berantakan)#

Notebook ini mengerjakan semua poin tugas:

  1. Hitung mean, std, skewness tiap channel (R, G, B) pada dataset

  2. Ubah citra ke greyscale

  3. Hitung fitur tekstur GLCM: energi, entropy, kontras, korelasi, homogenitas

  4. Simpan semuanya ke CSV (total 14 fitur + label)

2. Cek foto duplikat#

Di dataset ada foto yang isinya persis sama (byte per byte) padahal nama file-nya beda, misalnya dikumpulkan oleh dua orang yang berbeda. Kita deteksi pakai hash MD5: dua file dengan isi identik pasti punya hash yang sama.

Kenapa ini penting? Kalau satu foto masuk data training dan kembarannya masuk data test, model tinggal menghafal. Akurasi test jadi kelihatan lebih tinggi dari kenyataan.

3. Penjelasan fitur#

Tiap foto diubah jadi satu baris angka (fitur). Ada 14 fitur + 1 label.

a. Fitur warna (9 fitur)#

Dihitung per channel R, G, B dari seluruh piksel:

Fitur

Artinya

Mean

rata-rata nilai piksel → seberapa terang channel itu

Std (standar deviasi)

sebaran nilai piksel → seberapa beragam/kontras warnanya

Skewness

kemiringan distribusi → lebih banyak piksel gelap (positif) atau terang (negatif)

b. Fitur tekstur GLCM (5 fitur)#

Citra diubah dulu ke greyscale, lalu dibuat GLCM (Gray Level Co-occurrence Matrix): matriks yang menghitung seberapa sering sepasang piksel bertetangga punya tingkat abu-abu tertentu. Di sini dipakai jarak 1 piksel dan 4 arah (0°, 45°, 90°, 135°), hasilnya dirata-rata.

Fitur

Artinya

Energi

keseragaman tekstur (nilai tinggi = polos/teratur)

Entropy

tingkat keacakan (nilai tinggi = lebih acak/rumit)

Kontras

perbedaan intensitas antar piksel bertetangga

Korelasi

keterkaitan linear antar piksel bertetangga

Homogenitas

kedekatan nilai piksel bertetangga (tinggi = halus)

Secara teori foto berantakan “seharusnya” lebih acak. Tapi di dataset ini rata-rata kelima fitur GLCM antara rapi dan berantakan hampir sama (lihat tabel rata-rata per kelas di bagian 4). Itu sebabnya fitur tugas saja akurasinya terbatas.

Greyscale diubah ke 64 level (nilai piksel dibagi 4) supaya matriks GLCM lebih kecil dan cepat dihitung.

def glcm_feats(gray, distances=(1,), angles=(0, np.pi/4, np.pi/2, 3*np.pi/4)):
    g = (gray // 4).astype(np.uint8)                       # 256 level -> 64 level
    P = graycomatrix(g, list(distances), list(angles), levels=64, symmetric=True, normed=True)
    energy   = graycoprops(P, "energy").mean()
    contrast = graycoprops(P, "contrast").mean()
    corr     = graycoprops(P, "correlation").mean()
    homog    = graycoprops(P, "homogeneity").mean()
    p = P.mean(axis=(2, 3)); p = p[p > 0]                  # entropy dihitung manual dari GLCM
    entropy = -(p * np.log2(p)).sum()
    return energy, entropy, contrast, corr, homog

def ekstrak(path):
    bgr = cv2.imread(path)
    bgr = cv2.resize(bgr, (SIZE, SIZE), interpolation=cv2.INTER_AREA)
    r, g, b = [bgr[:, :, i].astype(float).ravel() for i in (2, 1, 0)]   # OpenCV = BGR
    gray = cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)                         # greyscale
    en, ent, con, cor, hom = glcm_feats(gray)

    return dict(
        mean_R=r.mean(), mean_G=g.mean(), mean_B=b.mean(),
        std_R=r.std(),  std_G=g.std(),  std_B=b.std(),
        skew_R=skew(r), skew_G=skew(g), skew_B=skew(b),
        energi=en, entropy=ent, kontras=con, korelasi=cor, homogenitas=hom)

5. Klasifikasi#

Data dibagi 80% training dan 20% test (stratify supaya proporsi rapi:berantakan sama di kedua bagian). Model belajar dari data training, lalu diuji di data test yang belum pernah dilihat.

Empat model dicoba: KNN, SVM, Random Forest, Decision Tree. Untuk KNN dan SVM fitur di-scale dulu (StandardScaler) karena kedua model ini sensitif terhadap skala angka.

Tiga jenis akurasi:

  • Akurasi train: skor di data yang dipakai belajar (kalau terlalu tinggi bisa tanda overfitting)

  • Akurasi test: skor di data baru, ini yang paling jujur

  • Akurasi CV (5-fold): data dibagi jadi 5 bagian; tiap bagian bergantian jadi data test (4 bagian lainnya training), lalu 5 hasilnya dirata-rata. Lebih stabil daripada satu kali split

Pembagian data: berapa untuk training, berapa untuk test?#

Cell di bawah menampilkan jumlahnya. Aturan yang dipakai:

  • 80% training, 20% test (test_size=0.2). Pembagian ini umum dipakai. Datanya cuma ratusan foto, jadi training tidak boleh terlalu kecil (model kurang belajar), dan test tidak boleh terlalu kecil (angka akurasinya jadi tidak stabil).

  • stratify=y → proporsi rapi : berantakan di training dan di test dibuat sama.

  • random_state=42 → pembagiannya acak tapi selalu sama tiap notebook dijalankan, jadi hasilnya bisa diulang.

sets = {"Warna (9 fitur)": COLOR, "Tekstur GLCM (5 fitur)": TEX, "Semua (14 fitur)": COLOR + TEX}
models = {
    "KNN": make_pipeline(StandardScaler(), KNeighborsClassifier(5)),
    "SVM": make_pipeline(StandardScaler(), SVC(kernel="rbf", C=10)),
    "Random Forest": RandomForestClassifier(300, random_state=42),
    "Decision Tree": DecisionTreeClassifier(random_state=42),
}
skf = StratifiedKFold(5, shuffle=True, random_state=42)
res = []
for sn, cols in sets.items():
    Xtr, Xte, ytr, yte = train_test_split(df[cols], y, test_size=0.2, stratify=y, random_state=42)
    for mn, m in models.items():
        m.fit(Xtr, ytr)
        res.append(dict(fitur=sn, model=mn,
                        acc_train=round(accuracy_score(ytr, m.predict(Xtr)), 4),
                        acc_test=round(accuracy_score(yte, m.predict(Xte)), 4),
                        acc_cv5=round(cross_val_score(m, df[cols], y, cv=skf).mean(), 4)))
R = pd.DataFrame(res)
R.to_csv(os.path.join(OUT, f"hasil_akurasi_{MODE}.csv"), index=False)

Akurasi CV tertinggi   : SVM (Semua (14 fitur)) = 72.8%   <- paling bisa dipercaya
Paling overfitting     : Decision Tree (Semua (14 fitur)) -> train 100.0% vs test 51.3% (selisih 48.7%)

Akurasi test dari 1 kali split bisa kebetulan tinggi/rendah (testnya cuma puluhan foto).
Jadi untuk memilih model terbaik, lebih aman lihat akurasi CV.

Cara baca tabel: bandingkan acc_train dengan acc_test. Kalau train jauh di atas test (misalnya Random Forest & Decision Tree yang train-nya bisa 100%), model menghafal data training dan kurang bisa menebak data baru → itu yang disebut overfitting. Fitur warna saja dan tekstur saja biasanya kalah dari gabungan keduanya.

6. Confusion matrix#

Matriks 2×2 yang menunjukkan hasil tebakan di data test:

  • baris = label aktual, kolom = label prediksi

  • diagonal (kiri-atas & kanan-bawah) = tebakan benar

  • di luar diagonal = tebakan salah

Dipakai model terbaik (berdasar akurasi CV) dengan 14 fitur.

best = R[R.fitur == "Semua (14 fitur)"].sort_values("acc_cv5", ascending=False).iloc[0]
cols = sets["Semua (14 fitur)"]; m = models[best.model]
Xtr, Xte, ytr, yte = train_test_split(df[cols], y, test_size=0.2, stratify=y, random_state=42)
m.fit(Xtr, ytr); pred = m.predict(Xte)
labs = ["rapi", "berantakan"]
cm = confusion_matrix(yte, pred, labels=labs)
print("Model terbaik:", best.model, "| akurasi test =", round(accuracy_score(yte, pred), 4))
print(classification_report(yte, pred))

fig, ax = plt.subplots(figsize=(4.5, 4))
ax.imshow(cm, cmap="Blues"); ax.set_xticks([0, 1], labs); ax.set_yticks([0, 1], labs)
for i in range(2):
    for j in range(2): ax.text(j, i, cm[i, j], ha="center", va="center", fontsize=16)
ax.set_xlabel("Prediksi"); ax.set_ylabel("Aktual"); ax.set_title(f"Confusion Matrix - {best.model}")
plt.tight_layout(); plt.savefig(os.path.join(OUT, f"confusion_matrix_{MODE}.png"), dpi=150); plt.show()

precision, recall, f1-score di atas adalah turunan dari confusion matrix: precision = dari yang ditebak kelas X, berapa persen yang benar; recall = dari yang sebenarnya kelas X, berapa persen yang berhasil ditemukan.

7. Akurasi training vs test (cek overfitting)#

Dari tabel di bagian 5 kita bandingkan akurasi training dan akurasi test untuk tiap model (14 fitur).

  • Kalau training dan test dekat → model belajar dengan baik.

  • Kalau training jauh lebih tinggi dari test → model overfitting: menghafal data training, tapi kurang bisa menebak foto baru.

r14 = R[R.fitur == "Semua (14 fitur)"].set_index("model")
ax = r14[["acc_train", "acc_test"]].plot.bar(figsize=(7, 4), rot=0)
ax.set_ylim(0, 1.05); ax.set_ylabel("Akurasi"); ax.set_title("Akurasi training vs test (14 fitur)")
for p in ax.patches:
    ax.annotate(f"{p.get_height():.0%}", (p.get_x() + p.get_width() / 2, p.get_height()), ha="center", va="bottom", fontsize=8)
plt.tight_layout(); plt.show()

print("Selisih training - test tiap model (makin besar = makin overfitting):")
for m_, r_ in r14.iterrows():
    print(f"  {m_:14s} train {r_.acc_train:.1%}  test {r_.acc_test:.1%}  selisih {r_.acc_train - r_.acc_test:.1%}")

Selisih training - test tiap model (makin besar = makin overfitting):
  KNN            train 81.6%  test 64.9%  selisih 16.8%
  SVM            train 93.2%  test 70.3%  selisih 22.9%
  Random Forest  train 100.0%  test 75.7%  selisih 24.3%
  Decision Tree  train 100.0%  test 51.3%  selisih 48.7%

Kenapa bisa overfitting? Datanya cuma ratusan foto dan fiturnya hanya 14 angka, jadi model gampang menghafal. Untuk laporan, akurasi yang dipakai adalah akurasi test (atau CV), bukan akurasi training.

8. Kesimpulan#

  • Fitur sesuai tugas: mean, std, skewness tiap channel (9) + energi, entropy, kontras, korelasi, homogenitas (5) = 14 fitur + label. Tersimpan di hasil/fitur_citra_<mode>.csv.

  • Duplikat: ada 9 grup foto kembar (10 foto dibuang di mode dedup) supaya akurasi test tidak palsu tinggi. Daftarnya ada di hasil/daftar_foto_duplikat.csv.

  • Pembagian data: 80% training, 20% test (random_state=42). Akurasi juga dicek dengan cross-validation 5-fold.

  • Training vs test: training jauh lebih tinggi dari test karena datanya sedikit (overfitting). Angka yang dilaporkan adalah akurasi test dan CV.

  • Akurasi dengan 14 fitur ada di kisaran 70%. Fitur warna dan tekstur memang mirip antara foto rapi dan berantakan, jadi akurasinya terbatas.
