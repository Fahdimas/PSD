Kenapa ini penting? Kalau satu foto masuk data training dan kembarannya masuk data test, model tinggal menghafal. Akurasi test jadi kelihatan lebih tinggi dari kenyataan.

Fitur

Artinya

b. Fitur tekstur GLCM (5 fitur)#

Citra diubah dulu ke greyscale, lalu dibuat GLCM (Gray Level Co-occurrence Matrix): matriks yang menghitung seberapa sering sepasang piksel bertetangga punya tingkat abu-abu tertentu. Di sini dipakai jarak 1 piksel dan 4 arah (0°, 45°, 90°, 135°), hasilnya dirata-rata.

Fitur

Artinya

Energi

keseragaman tekstur (nilai tinggi = polos/teratur)

Entropy

tingkat keacakan (nilai tinggi = lebih acak/rumit)

Kontras

perbedaan intensitas antar piksel bertetangga

Korelasi

keterkaitan linear antar piksel bertetangga

Homogenitas

kedekatan nilai piksel bertetangga (tinggi = halus)

Secara teori foto berantakan “seharusnya” lebih acak. Tapi di dataset ini rata-rata kelima fitur GLCM antara rapi dan berantakan hampir sama (lihat tabel rata-rata per kelas di bagian 4). Itu sebabnya fitur tugas saja akurasinya terbatas.

Greyscale diubah ke 64 level (nilai piksel dibagi 4) supaya matriks GLCM lebih kecil dan cepat dihitung.

def glcm_feats(gray, distances=(1,), angles=(0, np.pi/4, np.pi/2, 3*np.pi/4)):
    g = (gray // 4).astype(np.uint8)                       # 256 level -> 64 level
    P = graycomatrix(g, list(distances), list(angles), levels=64, symmetric=True, normed=True)
    energy   = graycoprops(P, "energy").mean()
    contrast = graycoprops(P, "contrast").mean()
    corr     = graycoprops(P, "correlation").mean()
    homog    = graycoprops(P, "homogeneity").mean()
    p = P.mean(axis=(2, 3)); p = p[p > 0]                  # entropy dihitung manual dari GLCM
    entropy = -(p * np.log2(p)).sum()
    return energy, entropy, contrast, corr, homog

def ekstrak(path):
    bgr = cv2.imread(path)
    bgr = cv2.resize(bgr, (SIZE, SIZE), interpolation=cv2.INTER_AREA)
    r, g, b = [bgr[:, :, i].astype(float).ravel() for i in (2, 1, 0)]   # OpenCV = BGR
    gray = cv2.cvtColor(bgr, cv2.COLOR_BGR2GRAY)                         # greyscale
    en, ent, con, cor, hom = glcm_feats(gray)

    return dict(
        mean_R=r.mean(), mean_G=g.mean(), mean_B=b.mean(),
        std_R=r.std(),  std_G=g.std(),  std_B=b.std(),
        skew_R=skew(r), skew_G=skew(g), skew_B=skew(b),
        energi=en, entropy=ent, kontras=con, korelasi=cor, homogenitas=hom)

5. Klasifikasi#

Data dibagi 80% training dan 20% test (stratify supaya proporsi rapi:berantakan sama di kedua bagian). Model belajar dari data training, lalu diuji di data test yang belum pernah dilihat.

Empat model dicoba: KNN, SVM, Random Forest, Decision Tree. Untuk KNN dan SVM fitur di-scale dulu (StandardScaler) karena kedua model ini sensitif terhadap skala angka.

Tiga jenis akurasi:

  • Akurasi train: skor di data yang dipakai belajar (kalau terlalu tinggi bisa tanda overfitting)

  • Akurasi test: skor di data baru, ini yang paling jujur

  • Akurasi CV (5-fold): data dibagi jadi 5 bagian; tiap bagian bergantian jadi data test (4 bagian lainnya training), lalu 5 hasilnya dirata-rata. Lebih stabil daripada satu kali split

Pembagian data: berapa untuk training, berapa untuk test?#

Cell di bawah menampilkan jumlahnya. Aturan yang dipakai:

  • 80% training, 20% test (test_size=0.2). Pembagian ini umum dipakai. Datanya cuma ratusan foto, jadi training tidak boleh terlalu kecil (model kurang belajar), dan test tidak boleh terlalu kecil (angka akurasinya jadi tidak stabil).

  • stratify=y → proporsi rapi : berantakan di training dan di test dibuat sama.

  • random_state=42 → pembagiannya acak tapi selalu sama tiap notebook dijalankan, jadi hasilnya bisa diulang.

6. Confusion matrix#

Matriks 2×2 yang menunjukkan hasil tebakan di data test:

  • baris = label aktual, kolom = label prediksi

  • diagonal (kiri-atas & kanan-bawah) = tebakan benar

  • di luar diagonal = tebakan salah

Dipakai model terbaik (berdasar akurasi CV) dengan 14 fitur.

7. Akurasi training vs test (cek overfitting)#

8. Kesimpulan#

  • Fitur sesuai tugas: mean, std, skewness tiap channel (9) + energi, entropy, kontras, korelasi, homogenitas (5) = 14 fitur + label. Tersimpan di hasil/fitur_citra_<mode>.csv.
